# Grabtamp Merchant APK

Public downloads of Android mock/testing builds for Grabtamp Merchant.

Open the repository's **Releases** section, select a build, and download its `.apk` asset. Android 8.0 or later is required. A checksum is supplied with each build.

These builds use local mock data. Phones do not synchronize data with each other, and no live backend or real settlement is connected.

Download URLs have no scheduled expiry. Availability depends on this repository, the release assets, and GitHub remaining available.
