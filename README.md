# Grabtamp Merchant — Android test APKs

Installable mock APKs are available in [Releases](https://github.com/saengsouly/Grabtamp-Merchant-APK/releases).

Latest test build: [0.1.1-mock APK](https://github.com/saengsouly/Grabtamp-Merchant-APK/releases/download/mock-2026-11-13-v0.1.1/Grabtamp-Merchant-0.1.1-mock.apk), Android 8.0 or later.

Download the APK on your Android phone, open it, and permit installation from your browser if Android asks. The version is 0.1.1-mock (code 2), signed with the same testing certificate as 0.1.0-mock.

These builds use independent local mock data, with no live backend or cross-device synchronization. They contain QA tools and use an Android Debug signature. They are intended for testing. Source code is not distributed in this repository.

Release URLs have no scheduled expiration; their availability depends on the hosting provider and repository remaining available. Checksums and limitations are recorded on each release.
